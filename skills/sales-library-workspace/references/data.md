# 三类资料的业务规则

## 知识库

保存标题、原文摘要、来源定位（段落/页码）、版本与读取时间。原文事实、个人总结、待验证推断明确分开。新版本与旧摘要冲突时先比对原文，再更新摘要，保留个人注释。库中内容不等于公开可分享内容。

## 料号库

以料号和地区版本识别产品，区分模板与可下单变体。保留原始料号文本、名称、单位、型号、地区、状态、组合/搭配规则与来源位置。不要用行号作为长期产品主键；行号只作本次证据定位。

旧表、隐藏表、停产与停用记录不能无差别作为可售产品。主机、电池、控制器和配件是否必须组合，以使用者自己的原始规则为准。库中库存快照必须带时间、仓库与指标含义；不认识的数量字段不能称为“可售库存”。

## 价格库

一条价格至少绑定产品、市场、币种、单位、数量档位、仓库/交付条件、价格类型、税项、有效起止日和证据位置；缺失字段保留 null 并说明，不补猜测值。金额用十进制字符串存储与 Decimal 计算，避免浮点累积。

同一料号可能有多个适用价格，不能取最低值替代规则匹配。系统计算价、标准价、手工成交价、代理价、演示机价和 MSRP 不混用。字段为 0 时先确认语义，不能自动认定免费；多字段累计或公式定价需查看真实系统规则。

目录刚更新但 PDF 仍过期：允许历史查询，输出“已过期，待确认”，不作为有效报价。有效期未知也不算有效。冲突时展示候选来源与适用条件，由用户或业务负责人明确优先级。`review_state=verified` 仅表示曾人工核验，报价时仍须重新比较日期与业务条件。

## 入库与更新

业务表中的 source_revision 与源快照不同，表示业务记录尚未跟上源版本。只有核验了当前内容才更新该字段。来源失败/删除不能自动删除业务记录或注释；先标记失效并说明原因。

本包不提供 PDF 全自动结构化定价器。先用文本提取定位，再查看相关页表头、脚注、合并单元格与适用范围；必要时人工确认。来源数据变成产品/价格记录是单独的核验步骤。
